# Inter 4.1

Official unmodified WOFF2 variable fonts from https://github.com/rsms/inter/releases/tag/v4.1.
Downloaded from https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip.
Normal and italic files support weights 100–900. The normal font is preloaded; italic loads only when needed. Served locally, with no external font requests. See LICENSE.txt for the SIL Open Font License.
